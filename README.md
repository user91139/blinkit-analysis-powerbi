# 📊 Blinkit Sales & Performance Analysis

## 📌 Brief One Line Summary

End-to-end data analysis and interactive dashboard built using Python and Power BI to analyze Blinkit sales and outlet performance.

---

## 🧾 Overview

This project analyzes sales data from **Blinkit (India’s Last Minute App)** to extract meaningful business insights. The analysis focuses on understanding product performance, customer preferences, and outlet-level trends using data analytics and visualization techniques. The project showcases real-world application of data analysis concepts through an interactive Power BI dashboard.

---

## ❓ Problem Statement

Blinkit operates across multiple locations, outlet types, and product categories. Due to large volumes of transactional data, it becomes difficult to:

* Track overall sales performance
* Identify top-performing products and outlets
* Understand customer purchasing preferences
* Support data-driven business decisions

This project aims to solve these challenges by converting raw sales data into meaningful insights.

---

## 📂 Dataset

The dataset contains structured grocery and retail sales data with the following attributes:

* Item Identifier
* Item Type
* Fat Content (Low Fat / Regular)
* Item Visibility
* Item Weight
* Outlet Identifier
* Outlet Type
* Outlet Size
* Outlet Location Type (Tier 1, Tier 2, Tier 3)
* Sales
* Ratings

---

## 💡 Key Insights

* Tier 3 outlets contribute the highest total sales
* Supermarket Type 1 outlets generate maximum revenue
* Low Fat products have higher sales contribution
* Fruits, Snacks, and Household items are top-selling categories
* Medium-sized outlets perform better compared to others

---

## 📊 Dashboard / Output

The Power BI dashboard provides:

* KPI cards (Total Sales, Average Sales, Items Count, Ratings)
* Item-wise and category-wise sales breakdown
* Fat content comparison visuals
* Outlet performance by size, type, and location
* Outlet establishment trend over time
* Interactive slicers and reset functionality

---

## ▶️ How to Run this Project?

1. Clone this repository
2. Open `Blinkit_Analysis.ipynb` in Jupyter Notebook to view analysis
3. Open `blinkit_dashboard.pbix` in Power BI Desktop
4. Use filters and slicers to explore insights
